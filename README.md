# Node — Система Управления VPS Сервером на Golang

Высокопроизводительное решение на **Golang** для управления удаленными VPS серверами с клиентским приложением и веб-интерфейсом в тёмной теме (в стиле референсов VixHub).

---

## 🌟 Архитектура проекта

Проект разделен на две независимые, сверхбыстрые части:

1. **VPS Agent (`cmd/server`)**:
   - Демон / сервер, который устанавливается на вашу VPS (Linux или Windows).
   - Написан на чистом Go для минимального потребления памяти (<15 МБ RAM) и мгновенного отклика.
   - Защищен авторизацией по `Secret Key` (Bearer токен).
   - Предоставляет REST API и потоковые SSE-каналы для логов.
   - Поддерживает безопасное создание публичных ссылок на файлы (`/share/{token}`).

2. **Client Manager (`cmd/client`)**:
   - Локальное приложение-клиент (Go) с встроенным адаптивным веб-интерфейсом.
   - Работает на Windows, Linux, macOS или локальном сервере.
   - **Переключатель серверов (Server Switcher)** в верхнем правом углу:
     - Мгновенное переключение между любым количеством VPS серверов.
     - Добавление новых узлов (Имя, URL, Secret Token).
     - Удаление серверов из списка.
     - Мониторинг статуса (Online / Offline) и измерение Ping в миллисекундах.
   - Проксирует запросы на активный сервер, исключая проблемы с CORS и утечкой токенов.

## 🚀 Основные разделы и возможности

### 1. 📁 Раздел «Файлы» (Файловый менеджер)
- Навигация по файловой системе (хлебные крошки `breadcrumbs`).
- Создание папок, загрузка файлов с компьютера на сервер.
- Скачивание файлов с VPS.
- **Публичный шеринг файлов (Share File)**:
  - Генерация уникальной безопасной ссылки вида `http://vps-ip:9090/share/<token>`.
  - Прямое скачивание по ссылке любым пользователем без необходимости ввода пароля.
  - Кнопка быстрого копирования ссылки в буфер обмена.
- **Встроенный редактор файлов**: просмотр и правка текстовых файлов/конфигов прямо в браузере.
- Удаление файлов и каталогов.

### 2. 🗄️ Раздел «Базы» (Базы данных PostgreSQL и MySQL)
- Поддержка двух СУБД: **PostgreSQL** и **MySQL**.
- Создание новых баз данных в 1 клик (`CREATE DATABASE`).
- Удаление баз данных.
- Проверка соединения с базой (тест подключения).
- **Режим «Чтение / Запись» (по референсу)**:
  - Поля: *Имя базы*, *Путь (ключ)*, *Значение*.
  - Чекбоксы: `Merge` (слияние данных/JSON) и `Force` (принудительная перезапись).
  - Кнопки: `↓ Читать`, `↑ Записать`, `🗑 Удалить`.
- **SQL Консоль**:
  - Выполнение любых произвольных SQL-запросов (`SELECT`, `INSERT`, `UPDATE`, `CREATE TABLE` и др.).
  - Вывод результатов в интерактивной таблице с отображением времени выполнения и количества строк.

### 3. 🐍📜🐹 Раздел «Скрипты» (Python, Node.js, Golang)
- Поддержка запуска скриптов на трех языках:
  - **Python** (`.py`)
  - **Node.js** (`.js`)
  - **Golang** (`.go`)
- **Автоматический поиск и установка зависимостей**:
  - Сервер анализирует импорты в коде перед запуском.
  - Для **Python**: автоматически выявляет сторонние библиотеки (например `requests`, `fastapi`, `flask`, `aiogram`, `telebot` и др.) и выполняет `pip install`.
  - Для **Node.js**: находит используемые модули (`axios`, `express`, `dotenv` и др.) и выполняет `npm install`.
  - Для **Golang**: создает `go.mod` и выполняет `go mod tidy` для подтягивания пакетов.
- Управление процессами:
  - `▶ Запустить` — компиляция/запуск в фоновом процессе с сохранением PID.
  - `■ Стоп` — принудительная остановка (kill) процесса по ID.
  - `≡ Получить логи` — вывод истории выполнения.
  - **Потоковый вывод логов (SSE)** в реальном времени в темный терминал.

## 🛠️ Сборка и быстрый старт

### Сборка на Windows:
Запустите скрипт сборки:
```cmd
build.bat
```
Или вручную через Go:
```cmd
go build -o bin/node-client.exe ./cmd/client
go build -o bin/node-agent.exe ./cmd/server
```

Для сборки агента под Linux VPS:
```cmd
set GOOS=linux
set GOARCH=amd64
go build -o bin/node-agent-linux-amd64 ./cmd/server
```

---

## 🌐 Установка агента на Linux VPS

1. Скопируйте файл `bin/node-agent-linux-amd64` на ваш сервер (например, в `/opt/node-agent/`):
   ```bash
   scp bin/node-agent-linux-amd64 root@YOUR_VPS_IP:/opt/node-agent/node-agent
   ```

2. Запустите агент вручную:
   ```bash
   chmod +x /opt/node-agent/node-agent
   /opt/node-agent/node-agent -port 9090 -secret "my_secret_token"
   ```

3. Либо установите как системную службу systemd:
   ```bash
   bash scripts/deploy.sh 9090 "my_secret_token"
   ```

## 💻 Запуск клиента управления

На вашем компьютере запустите:
```cmd
bin\node-client.exe
```
Клиент автоматически откроет браузер по адресу:
`http://localhost:8080`

В веб-интерфейсе:
1. Нажмите в правом верхнем углу на кнопку **Сервер... ▼**.
2. Введите URL вашего VPS: `http://YOUR_VPS_IP:9090` и укажите секретный ключ (если задан).
3. Нажмите **Сохранить сервер**.
4. Верхний баннер загорится зелёным цветом («Сервер в сети»), и вам будут доступны все разделы: Файлы, Базы данных и Скрипты!
