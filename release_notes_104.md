# Node Control v1.0.4

### ⚡ Новые возможности и улучшения:
- **Критическая остановка скриптов (SIGKILL / Force Kill):**
  - Добавлена кнопка `⚡ Убить` на панели скриптов рядом с кнопкой запуска/остановки.
  - Принудительное уничтожение всего дерева процессов (на Windows через `taskkill /F /T`, на Linux через `kill -9 -PID` и `pkill -9 -P`), а также немедленное прерывание pip/npm/go при зависании установки зависимостей.
  - Новый эндпоинт `POST /api/scripts/kill`.

- **Полное исправление запуска скриптов:**
  - Устранена проблема, из-за которой скрипт зависал в статусе "Выполняется" и не запускался повторно.
  - Исправлена буферизация Python: флаги `-u` и `PYTHONUNBUFFERED=1` гарантируют моментальный вывод `print(...)` в консоль WebSocket в реальном времени.
  - Добавлена автоматическая проверка живости процессов и очистка зависших задач перед стартом.
  - Установлен таймаут на авто-скачивание зависимостей, предотвращающий вечный лок.

- **Обновления по воздуху (OTA) через GitHub:**
  - Внедрена система обновлений напрямую с официального GitHub Releases (`kekih/node-control`).
  - Индикатор новой версии в верхней панели с анимацией и плашкой `🚀 Обновление v1.0.4`.
  - Модальное окно просмотра изменений и авто-установки в 1 клик.
  - Поддержка обновления для Windows, Linux Desktop, Android APK и Web.

### 📦 Прикрепленные файлы:
- `Node.apk` — Android приложение (v1.0.4)
- `node-client.exe` — Нативное настольное приложение Windows GUI
- `node-client-linux-amd64` — Нативное приложение Linux
- `node-agent.exe` — Серверный агент для Windows
- `node-agent-linux-amd64` — Серверный агент для Linux
